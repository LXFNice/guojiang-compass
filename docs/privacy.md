# 隐私政策

## 我们收集什么

**本版本为个人逆向研究版本，未新增任何个人信息收集行为。**

- **不要求注册账号**，不收集姓名、手机号、通讯录等身份信息
- 不上传用户的照片、文件、位置记录

## 权限与数据用途

- **传感器数据**：方向传感器数据仅在设备本地处理，用于显示方位，不会上传
- **位置权限**：仅在你主动使用「地理罗盘」功能时用于显示所在地信息，结果保留在本地，不会上传到服务器
- **存储权限**：仅用于下载更新安装包时写入文件

## 网络访问

本应用仅在以下情况发起网络请求：

1. **检查更新**：访问本项目 GitHub 仓库的 `update.json` 获取版本号，并在有更新时下载安装包
2. **应用内网页**：加载使用说明、服务协议、隐私政策的 GitHub 页面

除此之外，不向任何服务器发送用户数据。

## 第三方组件说明

本版本由原始应用逆向重建而来，程序内可能仍残留原应用集成的第三方稳定性与统计组件的初始化代码。在研究用途下，未进行任何针对个人信息的采集配置；如你对这一点有顾虑，可以选择不使用本软件。

## 你的权利

如对本隐私政策有疑问，或希望了解数据处理细节，可通过本仓库的 Issue 反馈。

# 使用说明

## 基本功能

果酱指南针是一款简洁实用的指南针工具。

- **指南针**：打开应用即显示当前方位角与方向
- **地理罗盘**：结合定位显示所在位置的地理方位信息
- **校准**：当指针出现偏差时，进入校准页按提示画「8」字完成校准

## 权限说明

- **传感器权限**：用于读取方向传感器数据（必需）
- **位置权限**：用于地理罗盘显示所在地信息（可选）
- **存储权限**：仅用于下载更新安装包时写入文件

## 检查更新

在「我的 → 关于」页面点击「检查更新」，应用会连接本项目仓库读取版本信息。当有新版本时，会提示下载并安装。

## 常见问题

**Q：指针不准怎么办？**

A：请远离磁场干扰源（如带磁扣的手机壳、音箱、电源线），然后进入「校准」页重新校准。

**Q：为什么需要校准？**

A：手机的方向传感器会受环境磁场影响产生偏移，定期校准可保证精度。

**Q：检查更新没反应？**

A：请确认设备已联网。`检查更新` 需要访问 GitHub 上的版本清单文件，网络不畅时会提示已是最新或无响应。

# 使用说明

## 基本功能

果酱指南针是一款简洁实用的指南针工具。

- **指南针**：打开应用即显示当前方位角与方向
- **地理罗盘**：结合定位显示所在位置的地理方位信息
- **常规页**：显示当前经纬度、磁场强度，并可反解所在地址
- **校准**：当指针出现偏差时，进入校准页按提示画「8」字完成校准

## 权限说明

- **位置权限**（`ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`）：用于常规页与地理罗盘显示经纬度、所在地信息。**不授予则看不到经纬度**
- **传感器权限**：用于读取方向传感器数据（必需）
- **存储权限**：仅用于下载更新安装包时写入文件
- **安装未知应用**（`REQUEST_INSTALL_PACKAGES`）：仅在应用内下载完更新包后，用于调起系统安装界面。可在「设置 → 应用 → 果酱指南针 → 安装未知应用」中单独开关
- **网络权限**：访问 GitHub 读取版本清单、按需加载说明/协议/隐私政策网页

## 检查更新

在「我的 → 关于」页面点击「检查更新」，应用会连接本项目仓库读取版本信息：

- 有新版本时弹出更新弹窗，点「马上更新」开始下载
- **下载过程中，弹窗内与通知栏都会实时显示下载百分比**
- 下载完成后会发出一个安装通知（或直接弹出系统安装界面），按提示完成安装即可

## 常见问题

**Q：指针不准怎么办？**

A：请远离磁场干扰源（如带磁扣的手机壳、音箱、电源线），然后进入「校准」页重新校准。

**Q：为什么需要校准？**

A：手机的方向传感器会受环境磁场影响产生偏移，定期校准可保证精度。

**Q：主界面看不到经纬度？**

A：请到「设置 → 应用 → 果酱指南针 → 权限」里允许「位置信息」，并确认手机已开启定位开关。2.0 之前的版本缺少位置权限声明，升级到 2.0 即可正常显示。

**Q：点「马上更新」下载完了却没弹出安装界面？**

A：第一次需要在系统提示时允许「安装未知应用」权限（或手动到「设置 → 应用 → 果酱指南针 → 安装未知应用」打开），之后即可正常调起安装。

**Q：检查更新没反应？**

A：请确认设备已联网。`检查更新` 需要访问 GitHub 上的版本清单文件，网络不畅时会提示已是最新或无响应。国内网络也可自行在 hosts 中把 `fastly.jsdelivr.net` 指向可用 IP。

**Q：从 1.x 升级到 2.0 有什么注意的？**

A：2.0 起**包名由 `com.study.research.test` 改为 `com.guojiang.compass`**，与旧版无法覆盖升级，属于两个独立应用。请**先卸载旧版再安装 2.0**，否则手机上会出现两个同名图标。
